# 支付二维码设置说明

## 📱 微信支付二维码

**文件位置**: `static/images/payment/wechat-qr.jpg`

**设置步骤**:
1. 打开微信，进入"我" -> "服务" -> "收付款"
2. 选择"二维码收款"
3. 设置收款金额（可选）
3. 截图保存二维码
4. 将图片重命名为 `wechat-qr.jpg`
5. 放入 `static/images/payment/` 目录

## 🔵 支付宝支付二维码

**文件位置**: `static/images/payment/alipay-qr.jpg`

**设置步骤**:
1. 打开支付宝，进入"收钱"
2. 选择"个人收款"
3. 设置收款金额（可选）
4. 截图保存二维码
5. 将图片重命名为 `alipay-qr.jpg`
6. 放入 `static/images/payment/` 目录

## 💡 使用建议

### 动态金额设置
- 可以为不同商品设置不同的收款金额
- 在二维码中显示商品名称和价格
- 方便客户确认支付信息

### 二维码管理
- 定期更新二维码（建议每月更新）
- 保持二维码清晰度
- 确保二维码大小适中（200x200px）

### 支付确认
- 建议客户支付后截图保存
- 提供联系方式供客户确认
- 及时处理支付确认和商品发送

## 🔧 技术说明

二维码图片会自动适配不同设备：
- 桌面端：200x200px
- 移动端：180x180px
- 支持响应式显示
