单词查词器

📚 一个简单实用的英文单词查词工具，帮助你快速了解单词的含义、发音和用法。

功能特点

  • ⚡ 极速查询：内置本地词典，常用单词瞬间显示结果
  • 🔍 智能搜索：本地词典优先，在线API备用，确保查询成功率
  • 🔊 发音功能：支持美式发音
  • 📖 丰富释义：提供详细的词汇解释和例句
  • 💾 查询历史：自动保存最近的查询记录
  • 📱 响应式设计：支持各种设备使用

使用方法

  1. 在输入框中输入要查询的英文单词
  2. 点击"查询"按钮或按回车键
  3. 系统会优先从本地词典查找，速度极快
  4. 如果本地词典没有，会自动使用在线API
  5. 查看详细的单词释义和例句
  6. 点击发音按钮听取单词读音
