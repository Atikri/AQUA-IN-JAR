How to Play

1. Connect islands (circles) with Bridges.

2. The number in the island tells you how many bridges connect to it.

3. Bridges can be single or double.

4. Bridges generally run horizontally or vertically and CANNOT cross.

5. All islands must be connected in a single network.


Controls: Click/Drag between islands to build bridges. Click again to make double or remove.
