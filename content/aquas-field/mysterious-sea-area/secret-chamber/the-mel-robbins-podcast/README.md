# The Mel Robbins Podcast

This section is automatically updated using the script `d:\AQUA-IN-JAR\scripts\fetch_mel_robbins.py`.

## How to Update

1.  **Install Prerequisites**:
    Double-click `d:\AQUA-IN-JAR\install_dependencies.bat` to install Python libraries.

2.  **Set API Key**:
    You need an OpenAI API Key set in your environment variables as `OPENAI_API_KEY`.

3.  **Run Update**:
    Run the following command in your terminal:
    ```powershell
    python d:\AQUA-IN-JAR\scripts\fetch_mel_robbins.py
    ```

The script will:
- Check for new episodes.
- Analyze them using AI.
- Generate a password-protected (0126) post here.
